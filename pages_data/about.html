Every disclosed bug, mapped to how it was found.

HexBrain is a map of 15,244 publicly disclosed bug bounty reports from 428 programs, grouped into 18 vulnerability classes and 215 weaknesses. Open a class, pick a weakness, and read how each bug was found, in the researcher's own words.

How to read the map

  • Each node on the inner ring is a vulnerability class. Each strip beyond it is a weakness, and each dot in a strip is one report.
  • Lines through the middle join classes that turn up in the same reports. Thicker lines mean more shared reports.
  • The Programs view is an index: a key for each letter, a strip for each program, and every program's logo on the rings inside. A letter opens a dial of its own, where each program is a hub.
  • Opening a program fans out what was reported to it, class by class, and then the domains it runs. Each strip opens in turn into its reports or its subdomains.
  • Opening a program can mark its reports on the vulnerability map, to show where that program has been hit.
  • The CVEs view is an index of years: a key for each year, a strip for each month, and inside the ring a red dot for every CVE known to be exploited. A year opens into a dial read like a clock, a month into its five bands, and a band into its CVEs.
  • The bypass library groups reports by the protection they got past: WAFs, filters, 2FA, earlier fixes and more.

Use it from an AI assistant

Claude, ChatGPT and other assistants can search the reports, read any write-up, pull a playbook for a bug class, and check what a program has already paid for. Access is read-only. Sign in with Google to create an API key and get the connection details.

Where the data comes from

  • The list of reports comes from the open hackerone-reports dataset.
  • Each write-up comes from that report's own public page on HackerOne. Every report here links back to it.
  • The payloads and techniques section is PayloadsAllTheThings by Swissky and contributors, used under the MIT licence.
  • The CVE library takes its checks from nuclei-templates (MIT licence), its exploited-in-the-wild list from CISA, and its likelihood scores from EPSS. Headlines and basic facts for every other CVE come from cve.now (CC BY 4.0).
  • The subdomains on program pages come from the Chaos public bug bounty dataset by ProjectDiscovery. Not every host listed is in a program's scope.
  • Where a program filed a report without a weakness, the class shown is our guess from the title, and the report page says so.
  • 9,875 write-ups are stored so far; the rest load from HackerOne the first time someone opens them.

Please use it responsibly

These reports describe real vulnerabilities that were fixed and then disclosed by the programs involved. Use them to learn and to test systems you are authorised to test, inside each program's scope.
