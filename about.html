About HexBrain

HexBrain is an interactive knowledge map of publicly disclosed HackerOne bug bounty reports, organized by vulnerability class, weakness, and program.

What it does

Every publicly disclosed HackerOne report is indexed, categorized, and mapped into a queryable knowledge base. You can browse by vulnerability class, drill into specific weaknesses, compare across programs, and read the full researcher write-ups.

AI integration

Connect Claude, ChatGPT, or any AI assistant to search HexBrain's database while you test. Sign in to generate an API key, then configure your AI assistant to use HexBrain as a tool.

Available tools

search_reports
Search disclosed bug bounty reports by keyword, vulnerability class, or program
get_report
Get the full write-up for a specific report by ID
list_weaknesses
List all weaknesses within a vulnerability class
list_programs
List all programs with their scope and report counts
search_payloads
Search the payload library by technique or vulnerability type
search_bypasses
Find bypass techniques by control type or vulnerability
